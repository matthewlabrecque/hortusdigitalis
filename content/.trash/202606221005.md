What is a GNFA? A GNFA (also known as a Generalized Nondeterministic Finite Automata) is used to convert a a DFA to a Regular Expression. It achieves this by reducing a DFA to a starting expression and accepting expression, creating a "black box" where the transition actually occurs

How to we go from a GNFA to an NFA? We have to translate our regular expression into a list of possible paths for the NFA

Is every FA language a regular language? Yes, all FA languages (both deterministic and nondeterministic) are regular languages.

What is Pumping Lemma? Pumping Lemma state that if A is a regular language, then for every string of sufficient length it's possible to create a substring and repeat it any number of times but it will still be part of the language

What are the three rules for Pumping Lemma? 1) for each i >= 0, x y^i z in A 2) |y| > 0 3) |xy| <= p

What is grammar of a language composed of? Variables (non-technical), terminals, and the rules of the language

If a Grammar G only has productions in the form A -> wB or A -> w, where A and B are variables and w is a terminal in a language (sigma*), what do we call the grammar? We call it a regular grammar

What does context free grammar? Context free grammar is a 4-tuple of <V, Sigma, R, S> where V is a finite set of values, Sigma is our alphabet present in the language, R is rules, and S is starting variable

What is Chomsky Normal Form? It's a subset of context-free grammar which standardizes CFGs into a strict and predictable structure, where every production rule yields one terminal rule

Why do we need Chomsky Normal Form? It removes redundancy and allows us to simplify CFGs.
